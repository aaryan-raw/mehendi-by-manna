# Mehndi by Manna: independent concept demonstration (not an official website)

Astro 5 + one React island (frontend-only Booking Demo). No backend, no analytics, no tracking.
Nothing entered in the booking demo is sent anywhere or stored. The site is `noindex` and has **not** been deployed.

    npm ci            # install from package-lock.json
    npm run dev       # http://localhost:4321
    npm run build     # static site in dist/
    npm run preview   # serve the build

**Start with:** `DEMO_GUIDE.md` (run and present the demo honestly), `OWNER_APPROVAL_CHECKLIST.md` (what the artist must approve), then **`HANDOFF.md`**: it lists what is real vs demo, the owner decisions needed before any public launch,
`SITE_URL`/social-preview setup, test results, known limitations and every changed file.

QA scripts live in `qa/` (see HANDOFF.md section 2).
